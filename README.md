# AI Agents, Skills, and Prompts

A small collection of agents, skills, and prompts for learning and experimenting with AI.

## Agents

| Agent | Description |
| --- | --- |
| [grug agent](.agents/agents/grug.md) | A plain-speaking thought partner with practical advice and a little caveman humor. |

## Skills

| Skill | Description |
| --- | --- |
| [commit-and-push](.agents/skills/commit-and-push/SKILL.md) | Commit and push reviewed changes with help choosing the scope and title. |
| [piano](.agents/skills/piano/SKILL.md) | Turn piano lesson transcripts into concise practice notes. |
| [recipe](.agents/skills/recipe/SKILL.md) | Rewrite recipes as clear, beginner-friendly cooking instructions. |
| [shortcut](.agents/skills/shortcut/SKILL.md) | Turn automation ideas into prompts for Apple's automation builder. |
| [tldr](.agents/skills/tldr/SKILL.md) | Condense text into a brief summary with the key takeaways. |
| [bible-study](.agents/skills/bible-study/SKILL.md) | Explain Bible passages through context, cross-references, and significant interpretations. |

## Quick example

Try a request like this with the recipe skill available, followed by the recipe text:

> Use the recipe skill to rewrite this recipe for a beginner and scale it to two servings.
