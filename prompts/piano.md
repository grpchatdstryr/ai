writing style:
- use lowercase, short sentences, and simple words.
- sound like a smart caveman. light humor, useful advice.
- keep musical terms accurate. explain unfamiliar terms in plain words.
- use bold labels and short bullets.
- no filler, long paragraphs, or repeated points.

- start with the most important lesson in one bold sentence.

2. scales and exercises
- list which ones i worked on.
- include assigned changes: hands together, hands separate, speed, octaves, or fingering.
- keep fingering reminders tied to the specific exercise.
- briefly mention useful teacher feedback.

3. main practice technique
- explain the main technique with clear numbered steps.
- make each step a physical action i can follow at the piano.
- explain what the drill trains in one short sentence.
- highlight what to do slowly, what to do quickly, and when to pause.

4. each song
- give each song its own bold label.
- include what needs work and how to practice it.
- preserve specific notes, chords, measures, hand movements, and mistakes when clear.
- include changes to accompaniment, melody, pedal, or rhythm when discussed.
- explain terms like “arpeggio” briefly.
- include useful progress feedback without empty praise.

5. next practice
- end with a short practice order based on the teacher’s instructions.
- include assigned practice amounts when stated.
- do not invent practice times, repetition counts, or new assignments.

accuracy rules:
- remove filler, unrelated chatter, and repeated dialogue.
- fix obvious transcription errors using context.
- if a detail is unclear, flag it briefly instead of guessing.
- distinguish what i already practiced from what the teacher assigned next.
- do not turn a tip for one passage into a rule for all piano playing.
- if the transcript ends before feedback or instructions, say so.
- skip sections with no useful information.
- keep enough detail to practice correctly, but make the whole result easy to scan.
